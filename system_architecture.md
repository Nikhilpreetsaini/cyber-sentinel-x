# System Architecture

The Cyber Sentinel X platform follows a modular architecture that separates data ingestion, analytics, correlation, presentation and reporting. The key components are:

1. **Data Ingestion Layer**: Users upload CSV log files via the Streamlit web interface. Built‑in demo generators provide synthetic logs for testing. The `log_parser` module normalises column names and prepares the data for processing.

2. **Processing Pipeline**: The `preprocessor` cleans the data, followed by the `threat_detector` which applies heuristic rules to classify events. The `risk_engine` computes risk scores and levels. The `ueba_engine` flags unusual behaviour, and the `incident_correlator` groups related events into incidents.

3. **Analytics & Intelligence**: MITRE ATT&CK techniques are mapped using the `mitre_mapper`, and IP reputation is looked up with `threat_intel`. Response playbooks are loaded from JSON via `playbooks`.

4. **Presentation Layer**: The Streamlit app serves multiple pages: a SOC dashboard, threat detection table, incident investigation interface, AI agent chat, and report generator. Visualisations are created with Plotly through the `visualizer` module.

5. **Case Management**: The `case_manager` maintains an in-memory registry of incident status, priority, analyst assignments and notes for interactive updates.

6. **Reporting**: Detailed incident reports and summary statistics are generated by the `report_generator` and offered as CSV downloads.

This layered approach ensures each module has a single responsibility, improving maintainability and extensibility. Additional analytics modules (e.g. machine learning classifiers) or external integrations (e.g. SIEM connectors) can be incorporated without major changes to the user interface.
